## 🚀 极简使用方法（直接喂给你的 AI Agent 全自动执行）

1. 下载并解压 `Google_One_SKU_Research.zip`。
2. 将解压后的文件夹直接丢给你的 **AI Agent（Antigravity / Claude Code / Cursor）**。
3. 让 AI 自动为你安装配置 **MuMu 模拟器 12（开启 Root 权限）**、升级新版 **Google Play 商店 (v43+)** 并安装 **x86 兼容版 Google One**。
4. 在模拟器中登录你的 Google 账号，双击运行 `00_一键总控菜单(推荐双击这个).bat` 或 `10_查Ultra促销档.bat`，即可自动扫描当前账号可领取的全部隐藏 Offer 并拉起官方收银台弹窗。
